# VRHand — VR без шлема (Roblox и другие VR-игры)

VRHand делает из клавиатуры и мыши «виртуальный шлем» и два «виртуальных контроллера» для SteamVR.
Для Roblox это выглядит как настоящий VR: шлем есть, руки есть, кнопки жмутся.

```
┌──────────────┐  UDP 127.0.0.1:49555  ┌─────────────────────┐        ┌────────┐
│ vrhand.py    │ ────────────────────► │ драйвер VRHand      │ ─────► │ SteamVR│ ─► Roblox
│ клавиатура + │  позы, кнопки, пальцы │ (driver_vrhand.dll) │        └────────┘
│ мышь         │                       │ шлем + 2 контроллера│
└──────────────┘                       └─────────────────────┘
```

> **Честно о статусе.** Код собирается и проходит автотесты (логика управления, формат пакетов,
> компиляция драйвера), но **с настоящим SteamVR и Roblox я его проверить не мог** — у меня нет Windows.
> Если что-то не заведётся с первого раза, см. раздел «Если не работает» и присылайте текст ошибки/лог.

## Установка (5 минут)

### 1. Скачать
Откройте на GitHub раздел **Releases** этого репозитория → релиз **«VRHand — последняя сборка»** → скачайте `VRHand.zip`.
(Если релиза ещё нет: вкладка **Actions** → последний зелёный запуск `build` → внизу **Artifacts** → `VRHand`.)

Распакуйте `VRHand.zip` в постоянное место, например `C:\VRHand\`.
**Не перемещайте папку после установки** — SteamVR запоминает путь.

### 2. Установить драйвер
1. Закройте SteamVR, если он запущен.
2. Дважды кликните **`install.bat`**.
3. Скрипт сам найдёт SteamVR, зарегистрирует драйвер и поправит настройки:
   `forcedDriver = vrhand`, `activateMultipleDrivers = true`, `enableHomeApp = false`
   (копия старых настроек — `steamvr.vrsettings.vrhand-backup`).

Если Windows пишет «Не удаётся запустить скрипт» — это окно `.bat`, оно обходит запрет само;
если SteamVR в нестандартном месте: `powershell -File scripts\install.ps1 -SteamVRPath "D:\Games\SteamVR"`.

### 3. Включить OpenXR (нужно для Roblox)
Запустите SteamVR → в окне SteamVR (≡) → **Настройки** → включите «Дополнительные настройки» →
вкладка **Разработчик** → **Set SteamVR as OpenXR runtime** (Установить SteamVR как среду выполнения OpenXR).

### 4. Проверить
SteamVR должен показать **один шлем и два контроллера** (значки зелёные) и маленькое окно виртуального дисплея.
Если шлем «серый» или есть ошибка — см. «Если не работает».

## Запуск (каждый раз)

1. Запустите **SteamVR** (виртуальный шлем появится сам).
2. Дважды кликните **`start_client.bat`** — откроется окно управления.
3. Кликните в окно управления — мышь «захватится», сверху станет зелёная надпись.
   `Esc` — отпустить мышь.
4. Запустите **Roblox**, зайдите в VR-плейс. В самом Roblox должен быть включён VR:
   меню (Esc) → Настройки → **VR: On** → перезапуск движка.
5. Играйте, **не сворачивая окно управления** (оно может быть позади — главное, чтобы мышь была захвачена,
   то есть последний клик был в нём). Окно по умолчанию держится поверх всех.

> Запустите клиент и SteamVR до Roblox, иначе Roblox может стартовать в обычном режиме.

## Управление

| Действие | Клавиши |
|---|---|
| Повернуть голову | мышь |
| Двигать **правую руку** | зажать **Shift** + мышь (колесо — вперёд/назад) |
| Двигать **левую руку** | зажать **Ctrl** + мышь (колесо — вперёд/назад) |
| Триггер выбранной руки | **ЛКМ** |
| Грип выбранной руки | **ПКМ** |
| Клик стиком | колесо-клик (СКМ) |
| Ходьба (левый стик) | **W A S D** |
| Поворот (правый стик) | **Q / E** |
| Правая рука A / B | **Пробел** (прыжок) / **R** |
| Левая рука X / Y | **T** / **Y** |
| Повернуть руку / крен | стрелки / **,** **.** (для выбранной руки) |
| Пальцы левой руки | **Z X C V B** (мизинец → большой) |
| Пальцы правой руки | **F G H J K** (большой → мизинец) |
| Сброс головы и рук | **Home** |
| Рост | **PgUp / PgDn** |

«Выбранная рука» — та, чей модификатор зажат. Без модификаторов ЛКМ/ПКМ работают с правой рукой.
Пальцы сгибаются плавно, пока клавиша зажата. Указательный палец заодно сгибается от ЛКМ, остальные три — от ПКМ.

**Про Roblox:** он использует только стандартные кнопки (стики, триггеры, A/B, меню), отдельные пальцы там не читаются.
Пальцы пригодятся в играх с Index-пальцами (например, VRChat).
Кнопки «меню» у виртуальных контроллеров пока нет (системная кнопка SteamVR зарезервирована); меню Roblox открывайте клавишей Esc на обычном окне Roblox или кнопками B/Y — как они назначены в Roblox VR, зависит от игры.

### Настройка
- Все клавиши — в начале `client/vrhand_core.py` (`FINGER_KEYS`, `KEY_...`). Правьте и перезапускайте клиент.
- Параметры запуска: `start_client.bat --sens 0.004 --hand-sens 0.002 --invert-y --height 1.7`
  (`--sens` — чувствительность головы, `--hand-sens` — рук, `--hand-pitch` — наклон контроллеров).
- Порт и размер окна дисплея — `vrhand\resources\settings\default.vrsettings`.

## Если не работает

**SteamVR пишет «Шлем не найден» / ошибка 108 / 306.**
Закройте SteamVR, снова запустите `install.bat`. Проверьте, что в `steamvr.vrsettings` (папка `Steam\config`)
в разделе `steamvr` есть `"forcedDriver": "vrhand"`. Лог драйвера: `Steam\logs\vrserver.txt` — ищите строки `[vrhand]`.

**Драйвер блокируется (SteamVR пишет, что драйвер не загрузился).**
В SteamVR: Настройки → Разработчик → «Управление драйверами / Manage add-ons» — убедитесь, что `vrhand` не отключён.
В `Steam\logs\vrserver.txt` ищите `vrhand`. Антивирус мог удалить `driver_vrhand.dll` — добавьте папку в исключения.

**Шлем и контроллеры есть, но Roblox не входит в VR.**
Проверьте OpenXR (шаг 3), VR=On в Roblox и перезапустите Roblox после запуска SteamVR.

**Контроллеры видны, а голова/руки не двигаются.**
Кликните в окно управления (должна быть зелёная надпись). Проверьте файрвол: драйвер слушает только `127.0.0.1:49555`,
порт можно поменять в `default.vrsettings` и в `--port`.
Быстрая проверка без мыши: `py -3 client\vrhand.py --demo` — шлем должен сам покачиваться.

**Roblox не реагирует на кнопки.**
В SteamVR → Настройки → Контроллеры → «Показать привязки» — убедитесь, что для Roblox используется профиль Index/«по умолчанию».

**Мышь «убегает» или окно мешает.**
`Esc` отпускает мышь. Поставьте `--no-topmost`, если окно управления мешает.

## Удаление
Закройте SteamVR → `uninstall.bat` (снимет драйвер и вернёт старые настройки SteamVR).

## Для разработчиков

```
driver/src/driver_main.cpp   драйвер SteamVR: HMD + 2 контроллера (Index), UDP-приёмник
driver/src/protocol.h        формат пакета (172 байта) — общий с Python
driver/CMakeLists.txt        сборка (нужен -DOPENVR_DIR=<клон ValveSoftware/openvr>)
client/vrhand_core.py        логика: мышь/клавиши → позы головы и рук (без Windows-кода)
client/vrhand.py             окно, чтение ввода (Windows), отправка по UDP, режим --demo
tests/                       тесты симулятора и совпадения формата пакета с C++
.github/workflows/build.yml  тесты + сборка DLL на Windows + публикация VRHand.zip
```

Тесты: `python -m unittest discover -s tests -v`.
Сборка релиза с версией: `git tag v1.0.0 && git push --tags`.
